# Security policy

This application handles highly sensitive financial data and is intentionally
limited to localhost.

Please report suspected vulnerabilities through a private GitHub security
advisory. Do not include real credentials, access tokens, account numbers,
transactions, balances, vault files, or other personal financial information in
an issue, pull request, screenshot, or test case.

The project has not received an independent security audit. Its threat model and
operating limits are documented in the README.
